# KiCAD source files

## Requirements

KiCAD 10.x or higher

The PCB and plate files were saved with KiCAD 10 and can't be opened in earlier versions.

## Dependencies

### Package Manager Libraries

Install the following library from KiCAD Package Manager:

- marbastlib (https://github.com/ebastler/marbastlib)
  - Install via the external ebastler KiCAD repository or from file

### External libraries

The following libraries are included as submodules:

- kleeb (https://github.com/crides/kleeb)
  - Components: rp2040-zero
- KiCAD_FootPrint (https://github.com/Salicylic-acid3/KiCAD_FootPrint)
  - Components: Keyswitch hole, stabilizer hole
- gh60 (https://github.com/komar007/gh60)
  - Components: Mounting hole
